- **裁定（2026-10-11 G-A）：批 A**——几何最近边命中（接管边 hover / click）。

- **现状复算**（口径 = fit 缩放全画布可见，沿每条边命中层路径中线每 `4` 用户 px 采样，`elementFromPoint` 判归属；「完全遮挡」= 全部采样点归属他人）：完全遮挡 = 主图 `8/38` / 前史 `2/8` / 卷 1 `8/41` / 卷 2 `9/36` / 卷 3 `1/20` / 卷 4 `4/18`（视图实例合计 `32`）；另 partial（可命中 < `60%`）主图 `6` / 卷 1 `11` / 卷 2 `14` 等。
