- **现状复算（本日 DOM，zoom `0.7505`，六视图扫描 `18` 候选）**：`transformer-2017`（epic）/ `berkeley-risc-1981`（major）渲染块高 = `52.0` flow px，`estimateBlockHeight` = `74` → 差 `22` px。机制 = 拉丁 `charW 0.6` 模型在 `100px` 边界高估：`Transformer` 估宽 `11×0.6×16 = 105.6 > 100`（估 2 行）vs 实渲染 1 行（≈ `88px`）；同机制 `Berkeley RISC`（major `14px`）。全站估 `74` 且 label 估 2 行者 `18` 节点：DOM 实测label 实渲染 1 行者 `3` 个（+ `macos-big-sur-2020`）——**端点侧外显 = 前 `2` 个**（`macos-big-sur` 无出边 → 端点对齐口径不受影响；b1 验收「`2` 节点 / `3` 视图出现 / `11` 边」成立）；其余 `15` 节点 label 实折 2 行（渲染 `72` = `2px` 系统差 = 灰字 margin 估 `+4px` vs 渲染 `2px`）。另注：视图内灰字降级节点的块高随「去 concepts 重排」同步收缩（主图 `godel` 放置 `blockH` = `40` = 渲染高 `40`，两遍放置口径），端点不漏配——唯一失配源 = 上述 label 行数高估。
