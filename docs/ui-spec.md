## 1. 坐标与刻度

画布：桌面优先；宽度动态 `W = Σ laneWidth + 2×24px`（视图内按年份含 `theory` 列节点时，最左增设 144px 前史单列，理论节点 x = 24 + 6）；单卷高 `H = 2000px`（前史卷 2160px，M0 实测），主图 `H = 2800px`；缩放平移交给 React Flow。

- 泳道顺序：`L0 → L5` 从左到右。
- 泳道宽：`laneWidth[i] = max(该泳道列数, 3) × 112px + 32px`；`laneBase[i]` = 前序泳道宽累加（例：L2 有 8 列 → 928px）。
- 列距：`columnOffset[j] = j × 112px`；节点文本块 `max-width: 100px`（允许断行）。
- 纵向刻度（每卷独立）：`px/年 = H / 卷年数`；年数按半开区间 `[start, end)`，边界年归后一卷（末卷含 2026）。

## 2. 节点与边渲染

- 节点 = 纯文本块：主标 + 灰字 `concepts`（最多 2 行 11px，超出以「…」截断，完整列表入详情框）；无边框、无填充。
- weight 映射：`epic → 16px/700`、`major → 14px/500`、`minor → 12px/400`；前者两档用 `var(--ink)`，minor 用 `var(--ink-soft)`。
- 交互态：hover → 淡底 `#00000008` + 邻居高亮（邻居 = 直接前驱 / 后继，淡底 `#00000004`）；选中 → 2px `--accent` 描边（描边画在未被 dim 的外层，dim 态下保持锐利）；BFS / 搜索 / 收敛三态 → 非相关节点与边 opacity 0.1。节点块 `cursor: pointer`（M2 起可点）。
- **灰字降级（M1 定）**：两遍放置——先按全 concepts 排，凡落入避让缺口（±20px 上限压不住）的节点在第二遍去掉 concepts 重排；被降级的节点块内不渲染灰字（详细内容仍入详情框）。同年 / 邻年密集簇（如 1936、1944）由此不出现压字。
- ParadigmBand（背景高亮带）：泳道内半透明底带 + 左缘竖排标签，置于节点层之下；v1 数据为空（`bands: []`），M3 有真实范式带后再定色值（不阻塞）。
- 边 = 正交折线（横-竖-横；同列取右侧旁路），无箭头；线型 / 线宽按 prd2 §3.5；hover 与点击均显示 tooltip（M2 落地 = 自定义浮层，非原生 title）：`source → target` + `relation 中文名` + `citation`（含 URL 时渲染为可点击外链）；hover 跟随光标、离开 180ms 收起，点击固定（标「已固定」），点空白 / 平移 / 切卷收起。relation 显示名：`enables → 使能`、`direct_fork → 直接分支`、`conceptual_inf → 概念影响`、`paradigm_shift → 范式转移`、`convergence → 收敛`、`composition → 组合`。

## 4. 详情框与引用

- 右侧固定面板（360px）：触发 = 单击节点（与 BFS 追溯同一次点击）或深链 `node=`；overlay 覆盖 + 自动平移避让（平移使节点落在左侧可视区中心，补偿面板半宽 180px）；打开时焦点移入面板、Esc 关闭并把焦点还给节点；`role="complementary"`（非模态，不锁画布）；窄屏 <1024px 降级为底部抽屉（45vh，断点 1023.98px）。
- **居中公式（M2 定）**：`setCenter(px + 50 + insetX / 2z, py + blockH/2 + insetY / 2z, { zoom: z, duration: 300 })`；`insetX = 宽屏面板开 ? 360 : 0`，`insetY = 抽屉模式 ? 0.45 × 画布高 : 0`；`z = 当前 zoom < 0.5 ? 0.75 : 当前 zoom`（<0.5 时 minor 不可见、concepts 已藏）。节点坐标取布局实排（不依赖 DOM 测量）。
- 面板内容：`label` + `label_en`、year（含争议备注 `year_note`，schema v5.3）、layer / column、weight、summary、concepts（全量，块内 ≤2 行截断的完整列表）、people、sources（`来源 N` 外链）、**核验行** `checked_at`（+ `archive_url` 存在时渲染「存档」链接）、**入边全列**（不受主图 ≤8 截断影响；行 = 源节点 · relation 中文名 · 年份 + citation 可点击；行可点击 → 选中并追溯该源节点）、**出边列表**（同格式）。layer 显示名映射：`PRE_theory` → 「前史」（哨兵层不代表泳道）。
- 外链 `target="_blank" rel="noopener noreferrer"`。
- 深链沿用 prd2 §6 格式；**加载即深链打开面板时不抢焦点**（a11y 例外，明记；用户点击 / 搜索打开才移焦）。

## 5. 交互状态机

| 动作 | 行为 |
|---|---|
| 搜索 | 范围 = `label` / `label_en` / `concepts` / `people`（大小写不敏感，中文子串）；排序 = label 前缀 > label 子串 > label_en 前缀 > 其余，年内升序；下拉 ≤8 行（label + 年份 + 跨卷时的卷名）；Enter 选中首条 / 当前高亮行；无结果显示「无匹配节点」；命中先闪烁（600ms 描边脉冲）并选中（= 平移居中 + 开面板 + 描边）；跨卷命中自动切卷 |
| BFS 追溯 | 点节点启动，全链不限深（250 节点规模）；非相关元素 α=0.1；范围 = 全局边集（跨卷，与当前视图无关） |
| 收敛高亮 | 与搜索 / BFS 互斥：启动时清除前两者；参与元素 = 全部 `convergence` 边及其两端，非参与元素 α=0.1（与 BFS 一致）；当前数据无 convergence 边时按钮 disabled（title 说明） |
| 深链 `node=` | 节点不在当前卷 → 自动切卷、平移居中、开详情面板；URL 显式 `vol=` 优先（节点在该卷不可见时才切到所属卷）；无效 id → 提示「节点不存在」并留在主图；深链不启动 BFS |
| 清除 | 点空白 = 清全部；Esc = 只关详情框（高亮与描边保留；搜索框内 Esc 只关下拉、`stopPropagation`）；手动改 URL 为无 `node=` 时按 URL 清选中 |
| 空态 | `sources` 为空显示「未核验」（防御性：schema 强制 ≥1 条，正常数据不可达） |

- 互斥与「选中」定义（2026-10-03 终审补）：三类高亮态 = BFS / 收敛高亮 / 搜索选中，任一启动即清除其余两者（后启动者胜）；「选中」（搜索命中、单击节点、深链）统一定义 = 描边 + 开详情框 + 平移居中，其中单击节点同时启动 BFS；详情框不参与互斥、不锁画布；Esc 只关详情框（高亮态保留），点空白清全部。
- M2 补充：**切卷 = 全重置**（关面板、清选中/高亮/tooltip——高亮集合跨视图不自洽）；URL 写回用 `history.replaceState`（不产生历史条目、不触发 hashchange），卷切换写 `vol=` 并清 `node=`，选中写 / 清 `node=`；搜索为全局（跨卷命中自动切卷）。

## 7. 响应式与性能

- v1 桌面（≥1024px）；缩放范围 0.25–2.5，默认 fitView。
- LOD：scale < 0.75 隐藏 concepts；< 0.5 再隐藏 minor；避让降级节点恒不显示 concepts（§2）。
- 性能观测：主图节点 ≤45；单卷 ≤60；不引入虚拟化（总量 ≤300 DOM）；bundle 目标 ≤500KB gzip。
- **性能测量口径（M2 定）**：prd2 §10「上下游追溯在 250 节点下响应 < 100ms」= ① `npm run bench`（`scripts/bench-bfs.ts`）：确定性合成 250 节点图（含 convergence 边与入边超限 hub），复用 App 同一 `src/lib/graph.ts`，测单次追溯全量计算 p50/p95，p95 > 100ms 退出码 1；② dev fixture（`?fixture=1`，仅 dev 构建，prod 剔除）实排 62 节点主图，实测 click→面板出现 37–65ms（dev 未压缩）。M3 真实数据齐后两者复跑〔B5 批完成（2026-10-09）：真实 193 节点 / 203 边 p95 0.036ms（报告段，不设 gate）〕。
- 响应式断点：`1023.98px`（CSS 媒体查询与 JS `matchMedia` 同值，抽屉 / 侧栏分界）。
- 数据加载失败：全局错误卡 + 重试按钮。

## 8. 控件布局（F-E-3，M2 定）

- 顶栏右侧槽位（`marginLeft: auto`）：**搜索框**（180px，结果下拉挂其下、右对齐、≤8 行）+ **「收敛」toggle**（显示收敛边数，如 `收敛 42`；无 convergence 边时 disabled）。<1024px 顶栏允许换行（`flexWrap`）。
- 搜索结果行 = label + 年份（跨卷命中追加卷名，如 `· 卷 1`）。
- 详情框与边 tooltip 均为覆盖层，不挤占画布（tooltip `z-index` 高于面板；通知条居中置顶，`role="status"`，4s 自动消失）。
