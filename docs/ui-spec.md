状态：2026-10-04 · v0.9（M1 批：前史段 6.3 → 6.8px/年〔段高 632〕；主图容器 2800；段高合计 2713；灰字降级规则；ParadigmBand 渲染一句；§5 空态更正）· v0.7（M0 实测批：前史段 3 → 6.3px/年；主图容器 2750；前史卷 H 2160；前史单列 x 槽位定义）· v0.5（blocking 修复批：卷 4 → [2015, 2027) 12 年；分段 55px/年；L2 = 6 列）· 与 prd2 冲突时以 prd2 为准

## 1. 坐标与刻度

画布：桌面优先；宽度动态 `W = Σ laneWidth + 2×24px`（视图内按年份含 `theory` 列节点时，最左增设 144px 前史单列，理论节点 x = 24 + 6）；单卷高 `H = 2000px`（前史卷 2160px，M0 实测），主图 `H = 2750px`；缩放平移交给 React Flow。

- 泳道顺序：`L0 → L5` 从左到右。
- 泳道宽：`laneWidth[i] = max(该泳道列数, 3) × 112px + 32px`；`laneBase[i]` = 前序泳道宽累加（例：L2 有 6 列 → 704px）。
- 列距：`columnOffset[j] = j × 112px`；节点文本块 `max-width: 100px`（允许断行）。
- 纵向刻度（每卷独立）：`px/年 = H / 卷年数`；年数按半开区间 `[start, end)`，边界年归后一卷（末卷含 2026）。

## 2. 节点与边渲染

- 节点 = 纯文本块：主标 + 灰字 `concepts`（最多 2 行 11px，超出以「…」截断，完整列表入详情框）；无边框、无填充。
- weight 映射：`epic → 16px/700`、`major → 14px/500`、`minor → 12px/400`；前者两档用 `var(--ink)`，minor 用 `var(--ink-soft)`。
- 交互态：hover → 淡底 `#00000008` + 邻居高亮；选中 → 2px `--accent` 描边；BFS 态 → 非相关节点与边 opacity 0.1。
- **灰字降级（M1 定）**：两遍放置——先按全 concepts 排，凡落入避让缺口（±20px 上限压不住）的节点在第二遍去掉 concepts 重排；被降级的节点块内不渲染灰字（详细内容仍入详情框）。同年 / 邻年密集簇（如 1936、1944）由此不出现压字。
- ParadigmBand（背景高亮带）：泳道内半透明底带 + 左缘竖排标签，置于节点层之下；v1 数据为空（`bands: []`），M3 有真实范式带后再定色值（不阻塞）。
- 边 = 正交折线（横-竖-横；同列取右侧旁路），无箭头；线型 / 线宽按 prd2 §3.5；hover 与点击均显示 tooltip：`source → target` + `relation` + `citation`（citation 含 URL 时渲染为可点击外链；M1 暂用原生 title，完整 tooltip 归 M2）。

## 3. 色板与字体

| token | 默认 | 用途 |
|---|---|---|
| `--bg` | `#FAFAF8` | 底色 |
| `--ink` | `#1A1A1A` | 主文字 |
| `--ink-soft` | `#6B6B6B` | 灰色小字（对 `--bg` ≈5.1:1，达 WCAG AA） |
| `--lane-a` / `--lane-b` | `#F4F4F0` / `#FAFAF8` | 泳道交替 |
| `--grid` | `#E8E8E4` | 时间网格 |
| `--rule` | `#D9D9D4` | 泳道分隔 |
| `--accent` | `#C0392B` | paradigm_shift 线、选中描边 |
| `--link` | `#2A6FBB` | 详情框链接 |
| `--dim` | `#B8B8B2` | 仅非文本装饰（禁用描边）；任何文本不得使用 |

- 字体栈（不加载 webfont）：正文 `system-ui, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`；卷题衬线 `"Songti SC", "SimSun", Georgia, serif`。
- 暗色模式：v1 不做。

## 4. 详情框与引用

- 右侧固定面板（360px）：触发 = 单击节点（与 BFS 追溯同一次点击）或深链 `node=`；overlay 覆盖 + 自动平移避让（平移使节点落在左侧可视区中心，补偿面板半宽 180px）；打开时焦点移入面板、Esc 关闭并把焦点还给节点；`role="complementary"`（非模态，不锁画布）；窄屏 <1024px 降级为底部抽屉 / 全屏。
- 面板内容：`label` + `label_en`、year（含争议备注）、layer / column、weight、summary、concepts、people、sources。layer 显示名映射：`PRE_theory` → 「前史」（哨兵层不代表泳道）。
- 外链 `target="_blank" rel="noopener noreferrer"`。
- 深链沿用 prd2 §6 格式。

## 5. 交互状态机

| 动作 | 行为 |
|---|---|
| 搜索 | 范围 = `label` / `label_en` / `concepts` / `people`；Enter 选中首条；无结果显示「无匹配节点」；命中先闪烁，选中后平移居中 |
| BFS 追溯 | 点节点启动，全链不限深（250 节点规模）；非相关元素 α=0.1 |
| 收敛高亮 | 与搜索 / BFS 互斥：启动时清除前两者 |
| 深链 `node=` | 节点不在当前卷 → 自动切卷、平移居中、开详情面板；无效 id → 提示「节点不存在」并留在主图 |
| 清除 | 点空白 = 清全部；Esc = 只关详情框 |
| 空态 | `sources` 为空显示「未核验」（防御性：schema 强制 ≥1 条，正常数据不可达） |

- 互斥与「选中」定义（2026-10-03 终审补）：三类高亮态 = BFS / 收敛高亮 / 搜索选中，任一启动即清除其余两者（后启动者胜）；「选中」（搜索命中、单击节点、深链）统一定义 = 描边 + 开详情框 + 平移居中，其中单击节点同时启动 BFS；详情框不参与互斥、不锁画布；Esc 只关详情框（高亮态保留），点空白清全部。

## 7. 响应式与性能

- v1 桌面（≥1024px）；缩放范围 0.25–2.5，默认 fitView。
- LOD：scale < 0.75 隐藏 concepts；< 0.5 再隐藏 minor；避让降级节点恒不显示 concepts（§2）。
- 性能观测：主图节点 ≤45；单卷 ≤60；不引入虚拟化（总量 ≤300 DOM）；bundle 目标 ≤500KB gzip。
- 数据加载失败：全局错误卡 + 重试按钮。
