## 2. 根因

- **文字重叠（`1` 处）**：年份定 y（同列同年零横向自由度）+ 同列单向下推 + `AVOID_LIMIT = 20`（`layout.ts:11`、`:201`）三者叠加；第二遍降级只含「被推方」不含「推挤方」（`layout.ts:243`），`ABC` 的 `54px` 块继续下压 → 残压 `7.55px`。`App.tsx` 不消费 `violations`（`:128`），违规只报不改。
- **边穿字（`66` 块）**：路由是端点坐标的纯函数（`TechEdge.tsx:35`，`my = (sourceY + targetY) / 2`），不读布局已算出的 `x / y / blockH`（`App.tsx` `positionsRef`）→ 竖段扫端点列（`46` 块）、横段扫中间列（`20` 块）；节点文本无填充（`ui-spec §2`）令线在字下可见。
- **共性**：布局 / 路由 / 绘制三套几何不共享「占用信息」。
